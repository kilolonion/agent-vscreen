2.0 正式版。以下是相对上一个正式版 1.4.1 的全部变化：PR #5–#54，包括 1.4.2-beta3～beta5、2.0.0-beta15 这几个预发布版，以及没有单独发布的 1.4.2-beta6 和 2.0.0-beta1～beta14、beta16。括号里是该改动首次出现的版本。可直接覆盖安装 1.4.x，签名不变。

### 新功能
- **任务中保持亮屏**（2.0.0）：有些手机上副屏会跟着主屏一起休眠，手机自动熄屏后任务就停了。打开这个设置后，只在 agent 任务进行时让屏幕不自动熄灭（可以变暗），任务一结束就恢复；按电源键熄屏照样有效。默认关闭。
- **Root 模式**（1.4.2-beta3）：已 root 的手机（Magisk / KernelSU / APatch）可以直接用 root 启动，不需要 Shizuku。
- **首页打开应用**（1.4.2-beta3）：不经过 agent，自己在副屏上打开应用。
- **更新渠道**（1.4.2-beta3）：可选只收正式版，或者测试版也收；更新说明按 Markdown 显示。
- **守门进程**（beta2）：端口由特权服务一直守着，App 休眠时连接也不会被拒；服务重启时 agent 会收到 `HOST_RESTARTED`。
- **短回复与页面卡**（beta3）：一切按预期时只报结果、不发图；同一页面再次出现时只报差异，动作期间的变化列在【这段时间】里。
- **外置记忆**（beta3）：每轮的步骤和结果存在手机上，agent 需要时再查。
- **闭环手势**（beta4）：`hold until` 按住直到满足条件再松手，`seek until` 把滑块拖到目标值；拖完如实报告停在落点、弹回还是消失。
- **`--hold`、`--on` 规则和时间提示**（beta5）：两轮之间可以暂停应用；一次 `act` 可以带上处理中途弹窗的规则；回复首行显示距上次回复多久。
- **强确认**（beta6）：接入新 agent、放宽权限、高风险和高频操作都要用指纹或锁屏密码确认；已确认的接入可以一键撤销。
- **公网 MCP 与设备码配对**（beta7、beta11）：云端 agent 可经 Tailscale Funnel、Cloudflare Tunnel 或 ngrok 接入，每个客户端都要在手机上核对批准；开通步骤直接写在页面上，每步配截图（beta8、beta12～14）。
- **每个 agent 一张权限表**（beta9），agent 可以申请更高许可（beta11）。
- **Agent 在等你时，屏幕顶部有紫色提示条**（beta13）。
- **无字图标识别**（beta3、beta4）：内置小模型，找没有文字的按钮和图标。
- **副屏任务切换、停放和小窗**（1.4.2-beta6、beta8）。
- **过热保护**（beta12）和 **App 内更新日志**（beta8）。

### 改进
- **更多手机能熄屏运行**（2.0.0）：系统不给“锁屏时可用”权限时，不再连带丢掉“副屏单独供电”；诊断里会列出系统拒绝了哪些副屏选项、原因是什么。
- **发热时少停读屏**（beta16）：轻度发热或充电时改用轻量引擎继续识别，温度更高才暂停；过热停机的门限不变。
- **本机端口被占时自动顺延**（beta16）：接入说明和命令行安装脚本都会往后找可用端口。
- **回复更省、更准**（beta1～beta16）：每条回复带计量；`act` 回复文字约减少 65%，图片 token 约减少 70～80%；`type` 后的等待、esc、输入结果、被遮挡的文字都按实际情况说明；MCP 工具表去掉重复描述；短回复的结构化结果只带显示出来的元素。
- **元素表更干净**（beta16）：列表行的图标不再被误读成文字；静止页面的回看不再被闪烁的光标填满；色块和任务回顾也修了。
- **接管和停止更可靠**（1.4.2-beta6）：你一接管或按停止，agent 之前排好的输入全部作废。
- **滑动更稳、读屏更稳、更省资源**（beta1、1.4.2-beta6、beta12）。
- **权限执行更严**（beta6、beta9～15）：本 App 不能被移到副屏；每分钟最多 120 步；坐标点击也会识别付款按钮；经公网接入的 agent 不能做系统操作。
- **Shizuku 授权失败时会说明怎么办**（1.4.2-beta4、beta5）：给出 OPPO / 一加 / realme、小米等机型对应的开关。
- **画面变化晚了不再报“没变化”**（1.4.2-beta5）。
- **设置和接入页重新整理**（beta8～11）；**“关闭”会停掉全部服务**（beta12、beta15）；**长文字不截断**（beta14）。
- **稳定性**（1.4.2-beta3）：后台线程出错不会让 App 崩溃，卡住的服务会超时报错。
