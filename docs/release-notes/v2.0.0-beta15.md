2.0 预发布测试版，可直接覆盖安装 1.4.x，签名不变。

### 新功能
- **公网 MCP**：通过 Tailscale Funnel、Cloudflare Tunnel 或 ngrok 让云端 agent 接入，OAuth 配对、手机上核对配对码；设置步骤直接列在页面上，配标注截图。
- **每个 agent 单独的权限档位**：只看 / 稳妥 / 省心 / 全权 / 自定义，逐项可改；放宽需指纹。
- **强确认**：支付、接入新 agent、放宽权限等用指纹或锁屏密码确认，其他操作单击允许，可选本轮或今天内。
- **Agent 在等你时屏幕顶部提示**：通知静音也看得到；agent 会把要你做的事直接转告你。
- **手势闭环**：拖动、滑动后如实报告“停在落点 / 弹回 / 消失”；`--hold` 暂停应用、`--on` 规则。
- **无字元素识别**：内置小模型识别没有文字的按钮和图标。

### 改进
- 回复更短更准：等用户、esc、输入结果、画面小变化、被遮挡的文字都按实际情况说明。
- 首页电源按钮“关闭”会结束全部服务并退出 App；“常驻”后公网接入自动恢复。
- agent 的名字完整保存，过长时单行滚动显示。

### 下载
- `agent-vscreen-2.0.0-beta15.apk`：Android 11+，arm64，需要 Shizuku 或 root。
- `agent-vscreen-2.0.0-beta15.toolpkg`：Operit 工具包，需要 Operit 1.10 及以上。
