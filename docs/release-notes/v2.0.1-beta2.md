2.0.1 预发布测试版，相对上一个发布 v2.0.1-beta1（PR #70），签名不变，可直接覆盖安装。

### 新功能
- **日语界面**：新增日语，语言默认跟随系统，日语系统直接显示日语（#70）。

### 改进
- 设置里不再重复接入入口，接入功能只在接入页；“通用”排到“识别与录制”前面（#70）。
- 各页标题、左右边距和分组标题统一对齐（#70）。
- 首页向下滑动后状态胶囊收成小圆点，标题不再被挤掉；“全部记录”等入口带箭头、点按范围更大（#70）。
- 状态点卡片用固定首列，点不再压字，第二行对齐（#70）。
- 输入框统一正文字号，短标签加短提示，长说明放在框外（#70）。
- 任务详情和记录只显示真实截图，不再用灰色空格占位（#70）。

### 下载
- `agent-vscreen-2.0.1-beta2.apk`：Android 11+，arm64，需要 Shizuku / 兼容分支或 Root。
- `agent-vscreen-2.0.1-beta2.toolpkg`：Operit 工具包，需要 Operit 1.10 及以上。
