2.0.1 预发布测试版，相对上一个发布 v2.0.0（PR #56–#67），签名不变，可直接覆盖安装。尚未真机实测，主力机慎装。

### 新功能
- **令牌有效期可选**：默认长期，也可选 30 天 / 7 天 / 1 天；命令行、HTTP、Operit 还可选 10 分钟一次性接入码（#59、#67）。
- **熄屏时三种处理**：允许熄屏 / 任务中保持亮屏 / 需要时点亮，修复熄屏后副屏点不动（#63、#67，issue #48 #60）。
- **过热保护页**：实时温度与保护状态，过热自动停止可以关闭（#63，issue #61）。
- **公网配对更安全**：确认卡显示来源地址，同时弹出的卡片有上限，多出的排队、可用配对码找回；可选“仅在手动开启窗口时允许新配对”（#59、#67）。
- **关于项目与一键反馈**：设置里新增关于；诊断页可一键开 GitHub issue，敏感信息先脱敏（#57）。
- **MCP 2026-07-28 新协议**：同时兼容旧客户端（#66）。

### 改进
- 屏幕文字防注入：第三方页面文字统一清洗并隔离，不会伪装成系统提示（#66）。
- 付款语境判断改为看点击时的同一画面（#66）。
- 支持 Shizuku 兼容分支（Sui、AXManager 等），首次配置更容易改用 Root（#59）。
- 特权服务与 HTTP 加固；复制令牌、接入码时剪贴板不显示预览（#59）。
- 后台循环卡住会被发现并恢复（#64）。
- 长列表自动折叠（#56）。
- 发版签名隔离到只对版本标签开放的环境，无需手动批准（#58、#67）。
- README 精简，修正下载链接（#62、#65）。

### 下载

- `agent-vscreen-2.0.1-beta1.toolpkg`：Operit 工具包，需要 Operit 1.10 及以上。
