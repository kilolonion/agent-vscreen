2.0.1 预发布测试版（versionCode 75），正式发布签名与 2.0.0 一致，可直接覆盖安装。本版涵盖安全加固、双栈 MCP `2026-07-28`、OAuth CIMD、屏幕防注入隔离、金融应用默认确认、Android 16+ `fn` 探测及 `#48`/`#60`/`#61` 根因修复。

### 安全与协议升级
- **10 分钟一次性接入码与敏感剪贴板**：命令行（`VSCREEN_CODE`）、HTTP 与 Operit 改用仅驻留内存的 10 分钟单次接入码（`avc_...`），仅经本机/Tailnet 的 `POST /v2/pair/exchange` 兑换长期令牌；复制凭证和粘贴输入标记 `IS_SENSITIVE` 隐藏剪贴板预览。
- **公网 MCP 配对、OAuth 2.1 CIMD 与每配对隔离**：外部配对静默入队绝不自动弹窗，须手机输入 8 位配对码并核对来源地址后经锁屏生物识别/PIN 确认；新增可选 3 分钟严格配对窗口，24 小时空闲关闭仅计已认证请求；支持 OAuth CIMD（SSRF 全网段过滤 + 固定已校验 IP 直连 TLS 与原主机名验签，确认卡绿标显示“已验证元数据文档来源域名”），同一 CIMD URL 的每次独立配对隔离权限档位、任务与撤销；支持仅设备码客户端重启持久化。
- **双栈 MCP `2026-07-28` 与 `ext-tasks`**：完整支持无状态 `server/discover`（`supportedVersions`）、扁平 `CreateTaskResult`、`tasks/get` 终态内联结果、多步 `act` 确认安全续执行点、统一原子取消与先查后淘汰幂等缓存，同时保留旧版 `initialize` 兼容。
- **特权服务与 HTTP 加固**：特权屏幕服务（协议 19）对全部 Binder 事务强制校验调用方 UID，`EXEC` 经纯 JVM 白名单（运行时零 `sh -c`）；`HttpCore` 加固单调时钟超时截止、防走私、分块 SSE 与 500 键有界限流。

### 新功能与体验修复
- **金融应用默认确认与屏幕文字隔离**：内置 41 个金融/银行/支付钱包默认每次确认，通用应用按当前同页实时观测自动升为付款强确认；所有第三方屏幕文本、Toast 与回读均经 `ScreenText` 围栏与 `screen_data`（`untrusted: true`）隔离，严禁混入 `system_text`。
- **熄屏输入、保活、过热保护与看门狗（`#48`/`#60`/`#61`）**：新增熄屏三档策略与无障碍节点路由，按需点亮后直测目标副屏可达性且隔离普通保亮锁与主动唤醒锁；被动只读命令不重开回合；两段式过热迟滞与可关闭过热自动停止开关；`LoopWatchdog` 托管 App 与特权服务关键后台循环。
- **Android 16/17 与 `fn` 只读探测**：新增 `fn` 命令只读发现 Android 16+ `AppFunctions` 清单（瞬时错误不写空缓存）；三层动态发现 Shizuku、Sui、AXManager、Nightzuku、Shevery 等兼容分支，并改进首次配置中的显式 Root 回退；长列表自动折叠、一键脱敏反馈及 `TaskTitleBar` CJK 行高修复。

### 本预发布版待真机确认项
